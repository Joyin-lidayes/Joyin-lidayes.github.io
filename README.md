本项目为 jar 游戏小站开源项目，包含全部网页信息、下载地址，供大家参考讨论，同时也用作 GitHub Pages。

## 游戏数据

根目录的 `games.json` 是游戏列表。文件最外层必须是 JSON 数组，数组中的每一项都是一个游戏对象：

```json
[
  {
    "id": "a94f06bc1d7e5a28",
    "name": "游戏名称",
    "url": "https://example.com/download",
    "type": "jar",
    "contributor": "Joyin",
    "icon": "../img/none.png",
    "description": "游戏简介。",
    "extractCode": "abcd",
    "source": "蓝奏云"
  }
]
```

### 字段说明

| 字段 | 是否建议填写 | 类型 | 作用与规则 |
| --- | --- | --- | --- |
| `id` | **必须** | 字符串 | 游戏的稳定唯一标识，也是详情页和分享页地址的一部分。必须为 **16 位小写十六进制字符**（`0-9`、`a-f`），例如 `a94f06bc1d7e5a28`；不得重复，已有游戏的 ID 不要修改。 |
| `name` | **必须** | 字符串 | 游戏名称，用于首页搜索、列表展示、详情页标题和分享标题。 |
| `url` | **必须** | 字符串 | 下载地址；详情页“立即下载”按钮跳转到此地址。建议填写完整的 `https://` 链接。 |
| `type` | 可选 | 字符串 | 游戏类型标签，例如 `jar`、`sis`。未填写时显示 `jar`。 |
| `contributor` | 可选 | 字符串 | 贡献者/整理者名称。未填写时显示 `Joyin`。 |
| `icon` | 可选 | 字符串 | 详情页封面图片地址。未填写时使用 `../img/none.png`。相对路径会以 `html/detail.html` 所在目录为基准，例如站内图片可写 `../img/cover.png`。 |
| `description` | 可选 | 字符串 | 详情页中的游戏简介，按纯文本显示。未填写时显示“暂无简介信息”。 |
| `extractCode` | 可选 | 字符串 | 网盘提取码。仅填写非空且不为 `无提取码` 的值时，详情页才会显示并提供复制按钮。 |
| `source` | 可选 | 字符串 | 下载来源名称，例如 `蓝奏云`、`百度网盘`。未填写时，页面会根据 `url` 自动识别；无法识别时显示链接域名。 |

除以上字段外，当前页面不会读取其他字段；可以保留自定义数据，但不会显示或参与功能。

### 新增游戏

使用脚本生成带有唯一 ID 的基础对象：

```bash
node scripts/new-game.js "游戏名称" "下载链接"
```

脚本会输出可粘贴到 `games.json` 的对象模板，并检查现有 ID 是否合规且不重复。构建时也会校验每一项的 `id` 格式和唯一性。

### 注意事项

- `games.json` 必须是有效 JSON：字符串使用双引号，最后一项后不要加逗号。
- 新增、排序、改名或更换下载链接时，都不要修改已有的 `id`，否则旧详情页和分享链接会失效。
- 修改数据后运行 `node build.js`，以重新生成 `_site/g/` 下的静态分享页。
